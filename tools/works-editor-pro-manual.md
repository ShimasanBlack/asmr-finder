# works-editor-pro.html 使い方マニュアル

## 開き方
`C:/Users/seiya/Documents/asmr-finder/tools/works-editor-pro.html`
をブラウザ（Chrome推奨）でダブルクリックして開く。

---

## 画面構成（3カラム）

| カラム | 内容 |
|--------|------|
| 左 | 入力フォーム（作品登録・編集） |
| 中央 | 登録済み作品の一覧 |
| 右 | プレビュー・JSON出力（画面幅1400px以上で表示） |

---

## 作品を新規追加する手順

### ① DLsite情報を自動取込（推奨）
1. DLsiteの作品ページを開いてURLをコピー
2. 左カラム上部の **「DLsite URL」欄** にURLを貼り付ける
3. **「🔍 取込」ボタン** を押す
4. 作品名・サークル名・声優・評価・販売数・ジャンルが自動入力される

### ② 各フィールドを確認・調整

| フィールド | 内容 |
|------------|------|
| RJ番号 | 自動入力。形式：RJxxxxxxxx |
| 作品名 | 自動入力。必要に応じて修正 |
| サークル名 | 自動入力。「複製」ボタンで直前の作品からコピー可 |
| 声優（CV） | 自動入力。複数いる場合はカンマ区切り |
| 価格 | 手動入力（円、数字のみ） |
| 画像URL | 自動入力 |
| タグ | タグ候補チップをクリックして選択。コアタグ（睡眠導入/癒し/あまあま/R18/ほんのりR18）は必ず1つ選ぶこと |
| 評価 | 自動入力（例：4.5） |
| 販売数 | 自動入力（例：12345） |
| 説明文 | タグから自動生成。「🔄 再生成」ボタンで生成し直せる |
| CTA文 | タグから自動生成。「🎲 ランダム」ボタンで変更可 |

### ③ 追加する
- **「＋ 追加」ボタン** を押す
- 中央カラムの一覧に追加されたことを確認する

---

## 作品を編集する手順
1. 中央カラムの一覧から編集したい行をクリック
2. 左カラムが **編集モード**（青いバナー表示）になる
3. フィールドを修正する
4. **「💾 更新」ボタン** を押して保存

---

## 作品を削除する手順
1. 中央カラムの一覧で削除したい行にマウスを乗せる
2. 右端に表示される **「🗑」ボタン** を押す
3. 数秒間アンドゥ（取り消し）が可能

---

## 同じサークルの作品を連続登録するコツ
- サークル名フィールドの **「複製」ボタン** → 直前の作品のサークル名をコピー
- タグフィールドの **「複製」ボタン** → 直前の作品のタグをコピー

---

## 整合性チェック
- **「🔍 整合性確認」ボタン** を押すとコアタグのチェックが走る
- コアタグ（睡眠導入/癒し/あまあま/R18/ほんのりR18）がない → 赤でハイライト
- コアタグが複数ある → 黄色でハイライト
- Exportボタン押下時にも自動でチェックされる

---

## works.jsonを書き出してpushする手順

### 方法A：コピーボタン（推奨）
1. 右カラム下部の **「📋 JSONコピー」ボタン** を押す
2. `C:/Users/seiya/Documents/asmr-finder/data/works.json` をテキストエディタで開く
3. 全選択して貼り付けて保存

### 方法B：pushコマンドをコピー
1. ヘッダーの **「📂 pushコマンド」ボタン** を押す
2. Git Bashに貼り付けて実行

```bash
cd /c/Users/seiya/Documents/asmr-finder
git add data/works.json
git commit -m "feat: works.json更新"
git push origin main && echo "✅ 完了" || echo "❌ エラーあり"
```

---

## データの保存・復元について
- 入力中のデータは **ブラウザのlocalStorage** に自動保存される
- ページを閉じて再度開いても **前回のデータが復元**される
- ブラウザの履歴削除・キャッシュクリアをするとデータが消えるので注意

---

## タグのルール
- コアタグは必ず1つだけ選ぶ（複数・ゼロはNG）
- タグの表記ゆれは自動で正規化される（例：「安眠」→「睡眠導入」）
- 禁止タグ（「音声」「同人」「ボイス」など）は自動で除外される

---

## よくあるミス
| ミス | 対処 |
|------|------|
| DLsite取込がうまくいかない | URLをブラウザのアドレスバーからコピーし直す |
| コアタグが赤ハイライトになる | タグ欄でコアタグを1つ選択する |
| pushしてもサイトに反映されない | works.jsonに貼り付けて保存しているか確認 |
| 前回のデータが消えた | ブラウザのキャッシュをクリアしていないか確認 |
